My Music 2.0｜簡約白色版

電腦：解壓縮 ZIP 後，雙擊 index.html，以 Chrome 或 Edge 開啟，按「匯入音樂」選取 MP3。
手機：請將整個資料夾放到 HTTPS 網站（例如 GitHub Pages），在手機瀏覽器開啟該網址，匯入手機上的音樂檔案。
Android：在 Chrome 選單使用「新增至主畫面」或「安裝應用程式」（依瀏覽器顯示）。
iPhone：在 Safari 使用分享選單的「加入主畫面」。

注意：
1. 這是可安裝的網頁應用程式（PWA），不是原生 APK 或 iOS App。
2. 手機直接開啟本機 HTML 可能有功能限制，建議使用 HTTPS 網址。
3. 音樂檔案儲存在各自裝置的瀏覽器 IndexedDB，不會跨裝置同步。
4. 若瀏覽器儲存空間不足、清除網站資料或使用無痕模式，音樂可能消失；請保留原始 MP3。
5. 本機直接開啟 HTML 時，播放器可使用，但無法啟用離線 PWA 安裝功能。
