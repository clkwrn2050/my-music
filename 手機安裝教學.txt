My Music 3.0｜簡約白色・手機桌面安裝版

這是 PWA（可安裝網站），不是 APK 或 App Store 原生 App。

【先讓手機能開啟 APP 網址】
1. 將此資料夾內所有檔案（不是 ZIP）上傳到支援 HTTPS 的網站，維持原本檔名及同一目錄。
2. 例如 GitHub Pages：建立公開 repository，將所有檔案上傳至儲存庫根目錄；到 Settings → Pages，選 Deploy from a branch，選 main / (root)，儲存。
3. 等待網站發佈後，開啟 GitHub Pages 顯示的 https:// 網址，確認播放器能正常運作。
4. 請勿將私人 MP3 上傳到公開的 GitHub 儲存庫；只上傳播放器程式檔。

【Android】
用 Chrome 開啟上述 HTTPS 網址 → 右上角 ⋮ →「安裝應用程式」或「新增至主畫面」→ 確認。

【iPhone】
用 Safari 開啟上述 HTTPS 網址 → 分享圖示 →「加入主畫面」→「加入」。

【使用】
點手機桌面上的 My Music 圖示 → 匯入手機內 MP3 → 播放。電腦也可使用同一個 HTTPS 網址。

【重要限制】
- 沒有公開 HTTPS 網址時，不能保證直接安裝為手機桌面 APP；下載 ZIP 本身不會自動安裝。
- 歌曲儲存在各裝置瀏覽器本機，電腦與手機不會自動同步。
- iPhone / Android 可能因系統、瀏覽器、儲存空間及省電策略限制背景播放或離線保存。
- 清除網站資料、移除 APP 或儲存空間不足時可能失去匯入的歌曲；務必保留原始 MP3。
- 網站首次連線後，程式檔可由 Service Worker 快取供離線開啟，但不保證所有手機環境都持續保留。
